Manim adapter specialization: validation findings

2026-09-27 · Evidence snapshot · Subject-level layer demand and gradient direction

Overview

Decision: keep one shared LoRA for Manim. The current evidence does not support subject-specific adapter spawning or layer allocation.

The source contains 995 examples, 23 subjects, and 426 topic names. This analysis uses the existing 100-example held-out validation split, which represents 19 subjects. It is a single-checkpoint diagnostic, not a controlled test of specialist lesson quality.

The no-update base-weight probe shows similar layer sensitivity across represented subjects: layer 6 has the largest mean per-example gradient norm for all 19. The trained shared LoRA has some negative gradient cosines, but no clear subject blocks.

Plain language: the plots show where examples pull on the model and sometimes pull against one another. They do not show a reliable boundary that calls for separate adapters.

Safe to carry forward: subject-conditioned specialization is unproven here; the shared adapter remains the default. Do not claim that Manim lacks diversity or that specialization is impossible.

Evidence

All probe examples came from the same 100 held-out IDs. The base probe used original BF16 Qwen weights with zero optimizer steps. The LoRA probes used the trained epoch-2 checkpoint at step 1790 with four-bit base loading. Both used assistant-code-only loss. Their norm values are not directly comparable because weights and parameter spaces differ.

Findings

Similar observed peak

At the original base weights, every represented subject peaks at layer 6 under the mean per-example L₂ norm used here. The broad layer profiles are similar. This weakens the case for allocating different layers by these subject labels in this slice.

Plain language: the observed subjects appear to ask most strongly for change in the same layer.

Scope: 100 validation examples and one model revision. This measure averages individual norms. D-MoLE uses the norm of a task's aggregate base-weight gradient to rank layers before adaptation. The two scores are not mathematically identical.

Opposition exists without a clear subject partition

The LoRA gradient comparisons use exact A/B gradients from the saved epoch-2 adapter. Some example pairs oppose, including at layer 35 down_proj. However, subject-pair mean cosines at that module are mostly close to zero, without a persistent blue block separating named subjects.

Plain language: two examples can disagree locally even when they belong to the same subject. A negative cosine is a diagnostic, not an adapter assignment.

Scope: one checkpoint and one validation split. The single Algebraic Geometry within-subject pair has cosine −0.056 for all layer-35 projections and −0.116 at down_proj; it cannot establish stable within-subject conflict.

Unsupported conclusions

These plots do not prove that one adapter is sufficient, that Manim lacks task diversity, or that later layers reconcile concepts during training. Layer depth is not training time. No dynamic split was trained and compared against the shared adapter on held-out lesson quality in this analysis.

Four subjects are absent from validation. Three represented subjects have at most two examples. The report does not analyze topic-level partitions or multiple model seeds. A post-hoc search across many layer–subject pairs can find negative cells by chance.

Next experiments

Immediate decision: do not add subject-specific adapters from these diagnostics. Keep the shared LoRA and prioritize lesson quality.

If specialization becomes a goal again, treat it as a new controlled experiment: predefine a candidate partition or discover it on training data only; compare shared and split adapters with matched rank budget, training data, optimizer steps, and held-out evaluation. A split must improve held-out code or rendered-lesson quality without a material worst-group regression. Repeat across seeds before making a general claim.

This is optional future work, not a prerequisite for the current product.

Glossary

Base-weight probe

A forward and backward pass measuring loss gradients with respect to original Qwen weights, without changing them. Here it describes layer sensitivity before Manim adaptation.

Back to first use

Layer sensitivity

The size of a layer's gradient under a specified loss and sample set. A larger norm means a larger local response, not guaranteed benefit from an adapter.

Back to first use

LoRA

Low-rank trainable A/B matrices attached to selected model projections while the base model is frozen. This report's cosine plots measure gradients of the trained shared LoRA matrices.

Back to first use

Gradient cosine

The cosine similarity of two gradients measured at the same weights. Negative values indicate local opposing directions; they do not identify a task or prove separate adapters help.
